# Komga

Komga media needs a valid metadata-provider link. [Komf](https://github.com/Snd-R/komf) and similar
tools can add these links. Otherwise, add media to Ryot manually or set links in Komga:

1. Open a book's **Edit > Links** tab.
2. Add a link named `AniList`, `MyAnimeList`, `MangaUpdates`, `OpenLibrary`, `GoogleBooks`,
   `Google Books`, or `Hardcover`. Names are not case-sensitive.
3. Under **Settings > Integrations**, create a Komga integration.
4. Enter the base URL, such as `https://komga.example.com` or `http://127.0.0.1:25600`.
5. Enter an API key from Komga **User Settings > API Keys**.
