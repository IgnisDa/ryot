# Plex Yank

This integration adds all library media to `Owned`. Use [Plex Sink](./plex-sink.md) for progress.

1. For a Plex admin account, get a [device
   token](https://www.plexopedia.com/plex-media-server/general/plex-token/#devicetoken).
   For another account, a current [user
   token](https://www.plexopedia.com/plex-media-server/general/plex-token/#getcurrentusertoken)
   is sufficient.
2. Under **Settings > Integrations**, create a Plex Yank integration with the server details and
   token.
