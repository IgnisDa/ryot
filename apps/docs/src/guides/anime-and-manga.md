# Anime and Manga

## MyAnimeList

Register a MyAnimeList application to get a client ID.

1. Create a [MyAnimeList](https://myanimelist.net) account.
2. Go to [API](https://myanimelist.net/apiconfig) in your account preferences.
3. Select **Create ID** and use the `Web` app type. The redirect and homepage URLs can be any
   valid URLs; Ryot does not use them.
4. Submit the application and copy the approved client ID.
5. Set `RYOT_PLUGIN_MEDIA_MAL_CLIENT_ID`.
