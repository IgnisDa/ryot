# Movies and Shows

Configure TMDB, TVDB, or both.

## TMDB

1. Create a [TMDB](https://www.themoviedb.org) account.
2. Open [API settings](https://www.themoviedb.org/settings/api) and request API access.
3. Submit the application. For personal use, the application URL can be any valid URL.
4. Copy the **API Read Access Token**, not the API key.
5. Set `RYOT_PLUGIN_MEDIA_TMDB_ACCESS_TOKEN`.

## TVDB

1. Create a [TVDB](https://www.thetvdb.com) account.
2. Open [API information](https://www.thetvdb.com/api-information) and select **Get Started**.
3. Complete the prompts and copy the **API Key**.
4. Set `RYOT_PLUGIN_MEDIA_TVDB_API_KEY`.
