# Video Games

## IGDB

1. Create a [Twitch](https://twitch.tv) account.
2. Open your [developer console](https://dev.twitch.tv/console).
3. Register an application with a unique name.
4. Open **Manage**, generate a client secret, and copy the client ID and secret.
5. Set `RYOT_PLUGIN_MEDIA_TWITCH_CLIENT_ID` and `RYOT_PLUGIN_MEDIA_TWITCH_CLIENT_SECRET`.

## Giant Bomb

1. Create a [GiantBomb](https://www.giantbomb.com) account.
2. Navigate to your [API key page](https://www.giantbomb.com/api).
3. Generate and copy an API key.
4. Set `RYOT_PLUGIN_MEDIA_GIANT_BOMB_API_KEY`.
