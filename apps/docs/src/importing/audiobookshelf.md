# Audiobookshelf

Only media with an Audible ID, iTunes ID, or ISBN can be imported.

::: info
If Audiobookshelf auto-deletes podcast episodes, mark them as completed manually.
:::

1. Get an API token from the Audiobookshelf
   [authentication](https://api.audiobookshelf.org/#authentication) docs.
2. Enter the server details and token under **Settings > Import data**.
