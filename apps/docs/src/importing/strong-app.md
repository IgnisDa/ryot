# Strong App

The importer adds completed workouts. Exercise names that exactly match the built-in catalog after
case, whitespace, and punctuation normalization use the global catalog exercise. Unresolved
exercises and catalog exercises with an incompatible workout kind are created as custom exercises.
Custom exercise properties and workout set links are preserved.

1. In [Strong](https://www.strong.app), open **Settings > General > Export data**.
2. Upload the CSV file under **Settings > Import data**.
