# Movary

::: info
Set `RYOT_PLUGIN_MEDIA_TMDB_ACCESS_TOKEN` before import.
:::

Imports include all movies, Watchlist, ratings, history, and comments.

1. Log in to [Movary](https://movary.org) and open **Settings > Account > Personal data**.
2. Export `history.csv`, `watchlist.csv`, and `ratings.csv`.
3. Upload them under **Settings > Import data**.
