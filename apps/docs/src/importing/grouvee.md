# Grouvee

## Imported data

| Grouvee data      | Ryot result                  |
| ----------------- | ---------------------------- |
| `Played` shelf    | `Completed`                  |
| `Playing` shelf   | `In Progress`                |
| `Wish List` shelf | `Watchlist`                  |
| Other shelf       | New collection               |
| Rating            | Converted from 1-5 to 20-100 |

Reviews, status updates, playtime, and start and finish dates are preserved.

## Steps

1. Log in to [Grouvee](https://www.grouvee.com) and open settings.
2. Select **Export your collection to a CSV file** and wait for completion.
3. Download the CSV file and upload it under **Settings > Import data**.
