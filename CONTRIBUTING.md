# Contributing To Ryot

The [contribution guide](apps/docs/src/contributing.md) explains how to set up
the project and validate changes.

## Contributor License Agreement

External contributors must electronically sign the
[Ryot Individual Contributor License Agreement](CLA.md) before their pull
request can be merged. CLA Assistant will request a signature on the pull
request and record the agreement version that was accepted.

Only submit work that you have the right to contribute. If an employer or
another party may own rights in your contribution, obtain their permission
before you submit it. Identify third-party material and its license in the pull
request.
